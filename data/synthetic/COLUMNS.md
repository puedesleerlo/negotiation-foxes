# Column dictionary of the synthetic dataset

Generated by `python -m foxes.synthetic --episodes 2000 --seed 20260905`.
6,000 episodes (2,000 per domain), 142,736 moves. Deterministic given the seed.

## Design

Three domains and five counterpart families, rotating the family per episode so that
comparisons do not confound family with scenario (the same criterion as `hendrikx2012eval`).

| Domain | Issues | What for |
|---|---|---|
| `d1_price` | 1 continuous (21 steps) | The shape of the Elmtree case: two parties, one issue |
| `d2_case3` | continuous price + 2 discrete | The shape E1 needs |
| `d3_five` | 5 mixed issues | Where the weight estimators are put to the test |

| Family | Definition |
|---|---|
| `boulware` | concession exponent e ∈ (0.10, 0.60): holds back until the end |
| `conceder` | e ∈ (1.20, 4.00): yields quickly |
| `linear` | e = 1 |
| `hardliner` | does not concede: always asks for its maximum |
| `tit_for_tat` | reciprocates the other party's concession (behaviour-dependent) |

θ per episode: `rv ~ U(0.15, 0.55)` on the utility scale, `deadline ~ U{12..30}`,
weights `~ Dirichlet(1)`, preference directions opposite to the other party with probability 0.7.

**Important methodological note for reading the validations:** since the true weights are
sampled from Dirichlet(1), the control `f06` *is* the generating distribution of the weights
and is therefore optimal in log score by construction. Beating it in log score requires a lot
of information; beating it in CRPS is the realistic signal that a weight estimator contributes.

## `episodes.parquet` — one row per episode

| Column | Type | Description |
|---|---|---|
| `episode_id` | str | `<domain_id>-<n>` |
| `domain_id` | str | `d1_price`, `d2_case3`, `d3_five` |
| `seed` | int | episode seed (reproduces the exact run) |
| `cp_family` | str | counterpart family |
| `cp_rv` | float | **truth**: the counterpart's reservation value, on its utility scale |
| `cp_beta` | float | **truth**: concession exponent e |
| `cp_deadline` | float | **truth**: private deadline, in rounds |
| `cp_weights` | json | **truth**: issue weights, in the order of `domain.issue_ids` |
| `cp_k` | float | parameter k of the concession curve |
| `cp_value_maps` | json | **truth**: value functions per issue |
| `prot_*` | various | the same for the protagonist party |
| `n_rounds` | int | rounds used |
| `agreement` | bool | there was an agreement |
| `agreed_offer` | json | agreed offer, or null |

## `moves.parquet` — one row per action

| Column | Type | Description |
|---|---|---|
| `episode_id` | str | episode |
| `round` | int | round |
| `party` | str | `protagonist` or `counterpart` |
| `action` | str | `propose` |
| `offer` | json | offer, value per issue |
| `u_protagonist` | float | **truth**: utility of that offer for the protagonist |
| `u_counterpart` | float | **truth**: utility of that offer for the counterpart |
| `target_utility` | float | target utility of the proposer in that round |
| `accepted_by_other` | bool | the other party accepted that offer |

`u_counterpart` in the counterpart's rows is what the foxes receive as
`est_utility_to_proposer` in the **oracle condition** of the validation: it isolates the
estimator's error from the error of estimating the counterpart's utility.

## `outcomes.parquet` — one row per episode

| Column | Description |
|---|---|
| `agreement`, `u_protagonist`, `u_counterpart`, `joint_utility` | result |
| `nash_product` | product of surpluses over the reservation values |
| `dist_to_pareto` | Euclidean distance from the agreement to the frontier (value left on the table) |
| `dist_to_nash`, `dist_to_ks` | distance to the Nash point and to the Kalai–Smorodinsky point |
| `rounds`, `n_pareto` | rounds used and size of the frontier |

## Partitions

`foxes.validate.split_of(episode_id)` splits by hash of the `episode_id`: 40 % calibration,
60 % validation. The dispersion parameters of f02, f03, f04 and f09 are fitted **only** on
calibration; no number in the validation reports comes from data seen while calibrating.
